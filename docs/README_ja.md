Mojichi（文字ち）は、「文字」(Moji) と 「友達」(Tomodachi) を組み合わせた名前の仮想ペットです。豊富なカスタマイズ機能とインタラクション機能を備えています。

## Mojichiでできること
- :poultry_leg:    多種多様な食べ物を与える
- :raised_hand:    あなたの…バーチャルな手で…撫でてあげる
- :soap:    不潔で臭くならないように、きれいに掃除してあげる
- :skull:    様々な方法で殺す
